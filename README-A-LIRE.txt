GWEN & NICOLAS — VERSION AUTOMATIQUE

Aucune valeur Firebase n'est à modifier.
Le projet Firebase "plaisir-malin-et-coquin" et sa configuration Web sont déjà intégrés.

POUR PUBLIER SUR FIREBASE HOSTING

Windows : double-cliquez sur DEPLOYER-WINDOWS.bat
Mac : double-cliquez sur DEPLOYER-MAC.command
Linux : lancez ./DEPLOYER-LINUX.sh

Le script :
1. vérifie Firebase CLI ;
2. vous connecte à Firebase ;
3. sélectionne automatiquement plaisir-malin-et-coquin ;
4. déploie les règles Firestore ;
5. publie le site et affiche l'URL web.app.

PRÉREQUIS DÉJÀ VALIDÉS
- Application Web Firebase créée
- Authentication anonyme activée
- Firestore créé

IMPORTANT
Un navigateur ne peut pas autoriser automatiquement un nouveau domaine dans la console Firebase.
En utilisant l'URL Firebase Hosting en .web.app, aucune modification de GitHub Pages n'est nécessaire.
